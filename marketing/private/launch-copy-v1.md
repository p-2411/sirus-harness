## r/SideProject

Title: I built Sirus: Claude and GPT in the same terminal conversation

If you already ask one coding model to review another's work, Sirus is a side project I'd like you to try. I'm its maker.

It's an open-source terminal workspace where Claude and GPT can participate in the same conversation. Give one participant a small task, then bring in another model to review the changes with the earlier discussion available.

A first session I'd suggest:
1. Bring one bug or failing test from a project you know.
2. Ask one model to reproduce it, make the smallest fix, and run checks.
3. Ask the other to review the work without editing files. You inspect the diff and decide what to accept.

Sirus also keeps local project memory and file checkpoints. Participants share your project directory, so keep overlapping edits sequential.

It's MIT licensed, with no separate Sirus account. Bring your own supported provider access; provider charges and usage limits still apply.

Demo examples and install steps: https://trysirus.com/?utm_source=reddit&utm_medium=community&utm_campaign=first10&utm_content=sideproject

I'm looking for the first developers to try it on a real task. What would make a shared conversation useful enough for you to switch from separate terminals?
