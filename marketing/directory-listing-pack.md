### Medium description — 300–500 characters

Sirus brings your existing Claude and ChatGPT subscriptions into one terminal workspace, including multiple accounts per provider. ### Long description — 120–180 words

Sirus brings the Claude and ChatGPT subscriptions you already pay for into one terminal workspace, including multiple accounts from the same provider. It is built for developers who want to keep their AI coding work together as they move between models and tasks.

Connect your accounts with `/login`, choose a model with `/model`, and start a task in your project. You can explore a codebase, implement a change, run tests or bring another model into the conversation for a review. Named participants share the session history, while autonomous subagents can handle focused assignments. Persistent project memory carries decisions into later sessions, and file checkpoints let you restore earlier work.

The harness is free and open source under the MIT license. Your provider subscriptions keep their own access rules and usage limits. Optional Anthropic and OpenAI API keys are supported, with API usage charged by the provider. Install with npm and bring one small task to your first session.
